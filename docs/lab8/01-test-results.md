браузерный файл содержит 52 строки. В код приложения изменения не вносились.

Как посмотреть запуск самому:

```bash
npm run test:e2e:ui
```

Выбери сценарий слева и нажми кнопку запуска рядом с ним.
Справа будут видны страница и шаги сценария.
Инструкция по установке и остальным командам находится в README.
