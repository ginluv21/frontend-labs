# Как показать Playwright на Mac

## Подготовить заранее

Нужны Node.js 24 и интернет. Открой актуальную папку репозитория в VS Code.
Если репозиторий уже скачан, сначала получи свежие изменения через Git.
В терминале VS Code, находясь в корне проекта, выполни:

```bash
node --version
npm ci
npx playwright install chromium
```

Первая команда должна показать версию Node.js 24.
Команда установки Chromium сама скачает браузер для твоего Mac.
Браузер из Linux копировать не нужно. Расширение Playwright в VS Code
для запуска через терминал не обязательно.

## Что показать для Jest

Открой файл `testsout` в корне репозитория.
Там сохранен настоящий запуск на компьютере, где готовилась лабораторная,
а не запись запуска на Mac. В конце есть результат всех команд.
При необходимости можешь повторить Jest на Mac:

```bash
npm test
```

## Красивый просмотр сайта и шагов

```bash
npm run test:e2e:hosted:ui
```

Откроется отдельное окно Playwright.
Оно проверяет сайт `https://sova-skakalka-ginluv21.ginlove.chatgpt.site`.
Сайт локально запускать не надо, API-ключ тоже не нужен.

1. Разверни окно Playwright, чтобы преподавателю было видно страницу.
2. Слева выбери «Совет сохраняется и появляется в копилке».
3. Нажми кнопку запуска рядом с названием. Для всех сценариев есть Run all.
4. Дождись зеленой галочки. Нажми на название завершенного теста.
5. В Actions выбери шаг открытия сайта или заполнения вопроса.
6. Над страницей выбери After, чтобы показать результат этого шага.
7. Затем выбирай нажатие «В копилку» и переход в копилку.
8. Покажи, что сохраненный текст появился на странице копилки.

Если справа пусто и написано about:blank, выбери конкретный тест и шаг
после `page.goto`. Сам факт успешного запуска всех тестов еще не выбирает
нужный снимок для просмотра. При необходимости перезапусти выбранный тест.

Можно объяснять так:

«Сейчас Playwright открывает мой опубликованный сайт, вводит вопрос,
получает подготовленный ответ, нажимает сохранение и переходит в копилку.
Проверка смотрит не только на кнопку, но и на результат - совет в списке».

Страницы и код загружаются с настоящего хостинга. Ответы API подменены
внутри тестового браузера. Это позволяет повторять показ без зависимости
от бесплатной квоты и не менять общую копилку посетителей.

## Если нужен именно обычный браузер

```bash
npm run test:e2e:hosted:headed
```

Эта команда сама выполнит все три сценария в видимом Chromium.
Браузер после завершения закрывается, поэтому для спокойного разбора
и скриншотов удобнее UI-режим с выбором сохраненных шагов.

## Если нужен отчет

```bash
npm run test:e2e:hosted
npx playwright show-report
```

В отчете открой сценарий. Внутри есть снимок страницы и trace.
Trace позволяет разобрать шаги и состояния страницы.
Отчет создается на том компьютере, где запускались тесты;
готовые временные отчеты в Git не отправляются.

## Если npx не найден

На этом Mac должны быть установлены Node.js 24 и поставляемые вместе с ним
npm и npx. После установки заново открой VS Code и терминал.
Не копируй пути к Node.js с компьютера Linux из старых сообщений чата.
