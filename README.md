# Сова на скакалке

Лабораторная работа 4. Простой React-сайт в стиле 2000-х.
Вводишь вопрос - получаешь случайный шуточный совет из готового списка.
Без API, сохранения, сервера и дополнительных библиотек.

## Запуск и сборка

Проект создан через `npm create vite@latest` с шаблоном React.

```bash
npm install
npm run dev
```

`npm run build` собирает сайт в `dist`. Именно эта папка нужна хостингу.
Посетителю сайта устанавливать и запускать ничего не нужно.

## Требования лабы

- **Компоненты:** `App`, `AdviceForm`, `AdviceResult`, `Button`.
- **useState:** вопрос и ошибка в `App`, совет в `useAdvice`.
- **props:** данные и функции передаются из `App` в дочерние компоненты.
- **Общее состояние:** от `advice` зависят текст кнопки в `AdviceForm` и ответ в `AdviceResult`.
- **Функция в props:** `onQuestionChange` меняет состояние вопроса в `App`; `onSubmit` вызывает обработчик родителя.
- **Алиас:** `@` означает папку `src`, настроен в `vite.config.js` и `jsconfig.json`.
- **Собственный хук:** `useAdvice` использует `useState` и выбирает случайный совет.
- **shared:** общая кнопка `Button` ничего не знает о сове и подходит другим формам.

Хук может использовать хуки React и хранить состояние компонента.
Обычная утилита просто работает с данными и не вызывает хуки React.

## Файлы

- `src/App.jsx` - собирает страницу, хранит вопрос, проверяет его перед отправкой.
- `src/components/AdviceForm.jsx` - поле вопроса и кнопка.
- `src/components/AdviceResult.jsx` - полученный совет или пустое состояние.
- `src/hooks/useAdvice.js` - пять советов, выбор случайного без повтора подряд.
- `src/shared/Button.jsx` - общая кнопка.
- `src/components/Disclaimer.jsx` - шуточный дисклеймер на 300 слов.
- `src/index.css`, `src/App.css` - стили и одна простая CSS-анимация текста.
- `public/owl-poses.png` - твой лист поз совы. CSS показывает одну позу из картинки.

## Проверка

Пустой вопрос и пробелы дают ошибку. После ввода текста кнопка выдаёт совет.
Следующее нажатие даёт другой совет. Перезагрузка очищает состояние.
Вопрос ограничен 300 символами. На узком экране блоки сжимаются.

`package-lock.json` создаётся npm автоматически и не включён в учебный коммит.
`node_modules`, `dist`, файлы хостинга и настройки агента также исключены через `.gitignore`.
