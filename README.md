# Сова на скакалке

Учебный проект на React и Vite. Лабораторная работа 5 продолжает работу 4.
Сова отвечает по смыслу вопроса через Gemini на русском языке.
Канье выдаёт случайную настоящую цитату через kanye.rest на английском.

## Запуск

```bash
npm install
npm run dev
```

Для ответа совы локально нужен файл `.env.local` с переменной `GEMINI_API_KEY`.
Этот файл исключён из Git. Ключ нельзя называть с префиксом `VITE_`:
такие переменные доступны клиентскому коду.
Необязательная серверная переменная `GEMINI_MODEL` выбирает модель;
по умолчанию используется `gemini-3.1-flash-lite`.
На хостинге ключ хранится как секрет окружения, а не в исходниках.
Без ключа карточка совы показывает ошибку настройки, Канье продолжает работать.

`npm run build` собирает React через Vite и готовит сервер сайта.
`npm run preview` показывает локальную сборку с тем же API-маршрутом.
Проект изначально создан через `npm create vite@latest` с шаблоном React.

## Где что находится

- `src/App.jsx` - вопрос, проверка формы и сборка страницы.
- `src/api/client.js` - единый Axios instance: адреса, Accept, тайм-аут 65 секунд и интерсепторы.
- `src/api/advice.js` - запросы к серверу совы и к Kanye, приведение ответов к одному виду.
- `src/hooks/useAdvice.js` - состояние ответов, загрузка, ошибки, автозагрузка и `reload`.
- `src/components/AdviceForm.jsx` - вопрос и кнопка с блокировкой при загрузке.
- `src/components/AdviceResult.jsx` - карточка источника и список компонентов `AdviceText` через `map`.
- `src/components/Owl.jsx` - позы из общего изображения и смена реплик во время ожидания.
- `src/components/Disclaimer.jsx` - шуточный дисклеймер на 300 слов.
- `src/shared/Button.jsx` - общая кнопка без логики советов.
- `server/owl.js` - один маршрут: проверка вопроса, инструкция персонажа и запрос Gemini.
- `vite.config.js` - алиас и подключение этого маршрута при локальном запуске.
- `scripts/build-server.mjs` - упаковка собранного Vite-сайта и серверного маршрута для хостинга.
- `src/index.css`, `src/App.css` - стили и адаптивность.
- `public/owl-poses.png` - лист поз совы, одна поза показана через CSS.

## Путь данных

`App` вызывает `useAdvice`. Хук запускает API-функции через общий Axios-клиент.
Для совы выполняется `POST /api/owl` с вопросом. Сервер добавляет инструкцию
персонажа и обращается к Gemini, используя секретный ключ в заголовке.
Клиент получает только текст ответа. Ключ не включается в браузерную сборку.
Для Канье выполняется обычный запрос к публичному API напрямую из React.

Каждая API-функция возвращает список из одного ответа `{ id, text }` или пустой список.
Результат записывается в `useState` и передаётся карточке через props.
Карточка выводит ответы компонентами `AdviceText` через `map`.
Ключи `owl` и `kanye` постоянные: у каждого источника одна карточка ответа.

Состояния каждого источника: `loading`, `success`, `empty`, `error`.
Запросы независимы и идут параллельно. Ошибка одного не убирает ответ другого.
`reload()` обновляет оба источника, `reload('owl')` или `reload('kanye')` - один.
Повтор совы использует последний отправленный вопрос, а не изменённый черновик.
При открытии страницы сова даёт общий совет. После отправки учитывает вопрос.
После перезагрузки ответы не сохраняются.

Пока идут запросы, компонент `Owl` меняет позу и реплику каждые 2,8 секунды.
Его `useEffect` запускает таймер только во время загрузки и очищает его после неё.
Поза выбирается через положение фонового изображения, отдельные картинки не нужны.
CSS добавляет прыжки. Настройка уменьшения движения отключает анимацию и смену поз.
Таймер не задерживает ответы API. Технические названия остаются в коде и этой инструкции;
в интерфейсе сова сохраняет свой образ.

## Требования на оценку 5

- Реальные HTTP-запросы через Axios.
- Результаты в `useState`, список компонентов через `map`, стабильные `key`.
- Индикатор загрузки и недоступная кнопка до завершения запросов.
- `useEffect` автоматически загружает данные при открытии.
- Отдельные состояния ошибки и успешного пустого списка, кнопка повтора.
- API-функции отдельно от компонентов, все запросы React через один Axios instance.
- Собственный хук возвращает данные, состояние загрузки и `reload`.
- Request-interceptor выводит метод и адрес запроса в консоль.
- Response-interceptor показывает сообщения сервера, ошибки сети и тайм-аута.

## Что объяснить на защите

Хук может вызывать хуки React и хранить состояние компонента.
Обычная функция запроса получает данные, но не хранит состояние React.
Хуки вызываются на верхнем уровне компонента или другого хука, без условий и циклов.
`useCallback` сохраняет ссылку на `reload`, поэтому эффект с зависимостью `[reload]`
не запускает запрос после каждого изменения состояния.

В `useEffect` создан `AbortController`. Очистка эффекта отменяет его запросы.
В режиме разработки `StrictMode` проверяет эффект повторным запуском:
первые запросы отменяются, новые завершаются. Это не бесконечный цикл.

Axios выбран по требованиям оценки 5. Используем instance, общие настройки,
тайм-аут, интерсепторы и автоматический разбор JSON.
Интерсептор - функция, через которую проходят запросы или ответы клиента.
Для Gemini нужен серверный маршрут, потому что ключ должен оставаться секретом.
На сервере используется встроенный `fetch`, дополнительный SDK не нужен.

## Как показать состояния

1. Открыть страницу: два источника загружаются автоматически.
2. В инструментах браузера включить медленную сеть и обновить страницу:
   видны сообщения загрузки, кнопка недоступна.
3. Заблокировать `/api/owl` через Network request blocking.
   Обновить страницу: сова с ошибкой, цитата Канье остаётся.
4. Снять блокировку и нажать «Повторить» в карточке совы.
   В Network появится только запрос совы, цитата не изменится.
5. Для пустого списка использовать Local Overrides в Network и заменить тело
   успешного ответа на `[]`. Повторить запрос: появится сообщение об отсутствии советов.
   После проверки удалить переопределение ответа.
6. Проверить пустой вопрос и пробелы: ошибка, новые запросы не отправляются.
7. Ввести вопрос и отправить: сова учитывает вопрос, Канье цитирует.
8. Изменить черновик, не отправляя его, и повторить неудавшийся ответ:
   для совы используется предыдущий отправленный вопрос.
9. В консоли видны `POST /api/owl` и `GET https://api.kanye.rest/`.

Пустой ответ предусмотрен по требованиям лабы. Обычным запросом к источнику
его нельзя гарантированно получить. Проверка с подменёнными ответами проводится
отдельно от опубликованного сайта. Сетевые ошибки не заменяются выдуманными советами.
Сервер ограничивает вопрос 300 символами и ожидание Gemini 60 секундами.
Лимит Gemini показывается как ошибка с возможностью повторить запрос позже.
